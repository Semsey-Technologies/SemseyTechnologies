# privacy.html

## 1. What it does
`privacy.html` is the Transparency and Privacy Policy page. It provides a detailed, human-readable explanation of how the site handles user data, specifically focusing on the use of local storage instead of server-side databases.

## 2. Why it does it
To build trust and maintain full transparency with users. Since the site utilizes PWA features and `localStorage` to save preferences, it is ethically important to explain that this data is "Data Sovereign"—meaning it remains entirely on the user's hardware and is never collected or tracked by the developer.

## 3. How it does it
- **Plain Language Explanations:** Breaks down technical terms like `LocalStorage` and `Service Workers` into simple concepts ("memory banks").
- **Philosophical Context:** Explains the developer's journey and why a "local-first" approach was chosen (Privacy, Simplicity, and Open Source mindset).
- **Audit Links:** Provides a direct link to the site's GitHub repository so users can verify the code and storage logic themselves.
- **Third-Party Disclosure:** Explicitly mentions Formspree as the single external processor for contact form data.

## 4. Overall role
It serves as the legal and ethical foundation of the site. It reinforces the brand's identity as a "privacy-first" entity and provides a necessary resource for users concerned about data collection.
